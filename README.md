# Calculator

A Python desktop calculator built with Tkinter.

## Features

### Basic Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Backspace
- Clear

### Scientific Calculator
- DEG / RAD modes
- sin
- cos
- tan
- sqrt
- log
- ln
- pi
- e
- factorial
- powers
- reciprocal

### Communication Engineering Calculator

The project also includes a dedicated panel for selected communication engineering formulas, including:

- Power ratio → dB
- Voltage ratio → dB
- dB → Power ratio
- dBm → mW
- mW → dBm
- Wavelength
- Shannon capacity
- Free-space path loss
- Nyquist rate
- PCM bit rate

## Technologies

- Python
- Tkinter
- math
